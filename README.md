Esta hecho con PHP y Tailwind CSS. Solo incluye la parte visual de las tres pantallas. Los formularios no guardan ni comprueban datos y no hay base de datos.

Para verlo hay que copiar la carpeta en el servidor local (por ejemplo la carpeta htdocs de XAMPP), arrancar Apache y abrir index.php desde el navegador. Tailwind se carga desde internet, asi que hace falta conexion.

Las imagenes (logo, fondo de login/register y personajes) se colocan en assets/img. Si faltan, se muestran placeholders.
